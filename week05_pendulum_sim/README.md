## 一、实验目的

1. 掌握单摆小角简谐振动与非线性摆方程的数值建模；
2. 用 Runge-Kutta 4 阶积分求解双摆拉格朗日运动方程，观察混沌对初值敏感性；
3. 实践浏览器端交互工程（Canvas 渲染、指针拖拽、DOM 控件联动、localStorage 持久化）；
4. 实践版本控制工程规范：增量式 Conventional Commits 基线管理。

## 二、方法与技术实现

| 模块 | 实现 |
|---|---|
| 物理模型 | 单摆 `θ''=-(g/L)sinθ`；双摆拉格朗日方程闭式解（状态 [θ1,ω1,θ2,ω2]） |
| 数值积分 | RK4 四阶，每帧 8 子步，帧时钳制 33ms 防跳变 |
| 渲染 | 深灰科技背景 #1a1a24，摆球径向渐变+shadowBlur 发光，下摆 160 点半透明彩虹衰减拖尾 |
| 交互 | 3 组参数滑块、重置按钮、鼠标直接拖拽摆球设初始角（松手零初速）、4 天体预设胶囊（700ms 缓动过渡） |
| 持久化 | localStorage 自动保存/恢复 L1、L2、g，含数值校验与范围钳制 |

## 五、踩坑与 Debug 记录

1. **能量监控函数 bug**：势能写成 `(m1+m2)g·y1 + m2·g·y2`，重复计入 y1，造成"6.7 J 漂移"假象。通过沿流场数值梯度 vs 解析梯度对比定位，修正为 `m1·g·y1 + m2·g·y2` 后漂移降至 10⁻⁵ 量级。运动方程闭式解经与拉格朗日线性方程组交叉验证，完全一致。
2. **工作区两次被外部进程清空**：文件在提交间隔被仓库外进程删除，一次误入删除提交。教训：每轮增量完成即提交；`git add` 后核对暂存 diff；用 `git restore` / `git checkout <sha> --` 完整恢复。
3. **幽灵报错排查**：控制台 `resetAnimation is not defined` 实为浏览器旧标签页缓存的历史版本，当前代码零改动、强刷后 0 报错——排错前先核对报错堆栈与磁盘文件是否同一版本。

## 六、结论

RK4 积分的双摆模型在 60 s 模拟中能量漂移 <10⁻⁴ J 量级，数值稳定；系统对 10⁻⁴ 初值扰动在 20 s 内产生 O(10 rad) 轨道分离，验证了确定性混沌的初值敏感特性。交互与持久化功能全部通过验收。
